Personal coursework repo for [data-viz-class-material-w2026](https://github.com/dina-deifallah/data-viz-class-material-w2026).

## Sync class materials (button)

1. Open **Actions**
2. Select **Sync Class Materials**
3. Click **Run workflow**
4. Leave **dry_run** unchecked to commit + push (or check it to preview only)

The workflow pulls the latest instructor materials and:

- adds new weeks / notes / model answers / data / final-project files
- **keeps your completed `*_exercise.ipynb` notebooks** (ones without `YOUR CODE HERE`)
- refreshes incomplete exercise starters when the class repo updates them

It also runs weekly on Mondays (08:00 UTC).
